The controlled process is an air-frictionless mass-spring-damper type second-order system. The user can insert the process parameters, that is, mass $m$, damping coefficient $c$ and spring constant $K_s$. Values of $c$ and $K_s$ can be negative. Although the animation shows a wheeled car, the simulation assumes the mass floats parallel to the ground.

The process variable (controlled variable) $PV(t)$ is the mass vertical axis position, that is measured in meters by a hidden position indicator. The indication range is from $PV_{min}$ to $PV_{max}$. The user can change these limits (in meters) and insert an error (in meters) in the indicated position. The process is subject to the perturbation force $F_p(t)$. The manipulated variable is the control force $F_c(t)$ the final control element (linear motor) exerts on the process. The simulation model assumes all forces are contained in the mass horizontal axis.

The controller presents the following characteristics:

  • Reads the setpoint $SP(t)$ and the controlled variable $PV(t)$;
  • Computes the error $e(t) = SP(t) - PV(t)$;
  • Provides the output $OP(t)$;
  • Offers the user the following options:
    • Selecting the control mode (PID, Anti-windup PID or Bistable);
    • Directly adjusting the control force $F_c(t)$ when in MANUAL mode; and
    • Selecting Direct Action (DIR) or Reverse Action for the controller.

The drawing below shows the simulator basic equations. $M(t)$ represents the linear motor response. $F_{c_{max}}$ is the maximum magnitude the control force $F_c(t)$ can achieve.

$$F_c + F_p - F_d - F_s = m\ddot{PV}$$ $$F_s=k_sPV \qquad F_d=c\dot{PV} $$ $$e=SP-PV$$ $$OP=K_p\left(e+\frac{1}{T_i} \displaystyle\int e dt + T_d \dot{e} \right) + OP_o $$ $$F_c=(M)(OP) \qquad M_{ideal} = F_{c_{max}}$$ $$\frac{K_p}{T_i}=K_i \qquad K_pT_d=K_d$$ $$OP=K_pe+K_i\int e dt + K_d\dot{e} + OP_o$$

Gains $K_p$, $K_i$ and $K_d$, output $OP(t)$ and preload $OP_o$ are dimensionless. $SP(t)$, $PV(t)$, $e(t)$ and proportional band $PB = \frac{1}{K_p}$ are also dimensionless but are expressed in meters for convenience. The user can insert $K_p$, $K_i$, $K_d$, $OP_o$ and $SP(t)$ and watch the other variables. If the user prefers to enter $T_i$ and $T_d$ instead of $K_i$ and $K_d$, they simply need to select the ISA mode. The values of $T_i$ and $T_d$ are expressed in seconds. The output $OP(t)$ can vary between $-100\%$ and $100\%$.

This version provides four closed-loop control modes:

  • PID mode;
  • PD + I if $|e| < e_{Th}$ Anti-windup mode;
  • PD + I if $|D| < D_{Th}$ Anti-windup mode; and
  • Bistable mode.

By selecting the "PID" mode the user can:

  • Adjust $I_{max}$ to limit the integral component magnitude to a less-than-100% value;
  • Make the derivative component to be computed over $PV(t)$ instead of $e(t)$;
  • Insert the cutoff frequency (in Hz) of the low-pass filter applied over the derivative component; and
  • Bypass the low-pass filter.

By choosing the "PD + I if $|e| < e_{Th}$" mode the user can insert the error threshold magnitude $e_{Th}$ (in meters) that sets the integrator on.

When choosing the "PD + I if $|D| < D_{Th}$" mode the user can enter the derivative threshold magnitude $D_{Th}$ (in %) which turns the integrator on.

By selecting the "Bistable" mode the user can set the deadband (in meters) and the minimum and maximum values of $OP(t)$.

The user can turn on/off the following screen displays:

  • Animation;
  • Operating envelope limits - dashed/solid red lines;
  • $PV(t)$ - dark teal dashed line;
  • $PV(t)$ indication range - orange;
  • $SP(t)$ - dashed blue line; and
  • Proportional Band $PB$ - green.
The last three indications, as well as the SP manual slider, only appear when the controller is turned on. By activating the operation envelope viewing, the user is enabled to change the envelope limits.

The linear motor receives the command $OP(t)$ and converts it into the controlling force $F_c(t)$ according to the linear motor response curve $M(t)$, which can be ideal or non-ideal. The value of $F_c(t)$ is limited to vary between $-F_{c_{max}}$ and $F_{c_{max}}$. The user can enter the $F_{c_{max}}$ value (in newtons) and choose the linear motor curve type. When selecting non-ideal curve, the user can insert the central slope of the curve (sigmoid) and its deadspace (in %). The user can insert the linear motor dead time (in ms) and select Direct Action (DIR) or Reverse Action for the linear motor.

When the controller is switched on, the simulator activates a display that shows the $OP$ components and another display that shows $F_c(t)$. Through the $F_c(t)$ curve the user can see the shape of the linear motor response curve $M(t)$.

Setpoint $SP(t)$ can be constant or variable. There are several available $SP(t)$ options. The user can select an option and insert the limits $SP_{min}$ and $SP_{max}$ (in meters).

Perturbation $F_p(t)$ can be constant or variable. There are several available $F_p(t)$ alternatives. The user can choose a type and enter the limits $F_{p_{min}}$ and $F_{p_{max}}$, which are expressed in percentage of $F_{c_{max}}$.

Through the screen upper right corner menu the user can choose a preset scenario. The user can also change parameters of the selected scenario.

The closer the user's computer average frame rate (in FPS) gets to the expected frame rate, the more the simulation nears real time (see indicators displayed in the screen lower left corner).
